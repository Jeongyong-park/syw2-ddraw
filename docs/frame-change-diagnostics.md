# 전장 화면 변화 진단

FPS가 일정해도 유닛이 정지했다가 빠르게 움직이는 증상을 구분하기 위한 선택적 계측이다.
게임의 원본 primary surface를 출력 직전에 비교한다. 게임 틱이나 실제 모니터 표시 시각을
측정하는 기능은 아니다. 기본 비활성화이며 릴리즈 기본 설정과 게임 속도를 변경하지 않는다.

## 실행

측정 실행기를 시작하는 PowerShell에서만 다음 환경 변수를 설정한다.

```powershell
$env:HQCDD_PERF_REGION = '480,40,280,380'
# tools/perf_matrix.py의 기존 인수와 --trace-mode on --wait-for-ready로 실행한다.
# 게임을 직접 실행한다면 HQCDD_PERF_FILE도 CSV의 절대 경로로 지정해야 한다.
# 측정 실행기를 시작한 뒤 이 셸의 설정은 제거할 수 있다.
Remove-Item Env:HQCDD_PERF_REGION
```

좌표는 화면 배율 적용 전 게임 픽셀이다. 예시는 800×600 전장의 오른쪽 영역이며
하단 HUD를 제외한다. 너비는 1..800, 높이는 1..600, 시작 좌표는 0..8192이고,
영역 전체가 원본 화면 안에 들어와야 비교한다. 설정 문자열은 manifest의
`frame_region_requested`, 실제 DLL의 파싱 결과는 `hqcdd.log`에 남는다.

각 축 2픽셀 간격으로 RGB를 비교한다. 8비트 팔레트 색 변화도 반영하며,
16/32비트 입력도 지원한다. 원본에는 별도 창으로 그리는 HQCDD OSD가 포함되지 않는다.
현재 커서 위치가 영역 및 주변 64픽셀 이내에 있거나, 포커스를 잃거나, 디스플레이 설정이
열리거나 게임 본창 대신 별도 대화상자가 활성화된 경우 비교를 제외한다. 커서가 벗어난 뒤 250ms 동안 기다리고 새 기준 프레임을 만든다.
이 여유 범위는 보수적인 휴리스틱이며 임의 크기·지연의 소프트웨어 커서를 완전히
식별하는 기능은 아니다. 측정 중 커서를 영역에서 멀리 고정하고 영상으로 확인해야 한다.

## CSV와 보고서

- `frame_probe_cpu`: 커서 확인과 픽셀 비교에 걸린 CPU 시간. `output_attempt`에도 포함된다.
- `frame_region_baseline`: 첫 비교 기준 또는 제외 구간 이후의 새 기준. 변화량으로 세지 않는다.
- `frame_region_change`: `a`는 변경된 샘플 수, `b`는 비교한 샘플 수. `a=0`도 유효한 관측이다.
- `frame_region_unavailable`: 비교 불가. 기준을 끊고 정지 시간을 이어 붙이지 않는다.

기존 `perf_report.py`와 실행기의 `result.json`에 `frame_region`이 추가된다.
변경/동일 샘플 횟수, 제외 횟수, 관측된 동일 화면 연속 구간의 최대 시간,
변화 발생 간격, 평균/최대 변경 샘플 비율을 담는다. 추가 지표가 없으면
`available=false`이며, 실제 표시 FPS와 입력→화면 지연은 계속 미측정이다.
수집 종료까지의 미관측 꼬리 구간을 동일 화면 시간에 더하지 않는다.

## 해석

출력 간격이 정상인데 움직여야 하는 영역에서 동일 RGB 구간이 길어지면 게임 내부
갱신을 추가 조사한다. 출력 호출 자체가 멈췄다면 CPU 대기·렌더링·스케줄링 기록과
대조한다. 이미지가 정상적으로 변해도 화면이 멎어 보인다면 실제 표시 경로를 조사한다.

정지 병력·빈 지형도 같은 RGB를 만들며, 카메라 이동·깃발·팔레트 변화는 유닛 진행과
관계없이 RGB를 바꾼다. 샘플 사이 픽셀 변화는 놓칠 수 있다. 따라서 이 지표만으로
정지 원인, 유닛 속도, 밀린 틱 처리나 쓰로틀링을 확정하지 않는다.

## 검증 상태

네이티브 테스트는 영역 밖 변화 제외, 동일 RGB 팔레트 인덱스, 팔레트 색 변화,
16/32비트 입력, 크기·형식 및 기준 초기화를 검사한다. Python 테스트는 반복 후 변화,
제외 구간을 사이에 둔 시간 계산, 잘못된 샘플 수 및 미계측 상태를 검사한다.
첫 전장 시도 `output/perf-battle-region-20260911`는 준비 중 다른 프로그램으로
포커스가 이동해 중단했다.

`output/perf-battle-region-retry-20260911/run-00`에서 37창병 세이브를 불러오고
선택한 병력 집단에 세 차례 이동 명령을 주며 30.098초 측정했다.

화면 비교 CPU 시간은 제외 판정까지 포함한 608회 기준으로, 계측 ON/OFF의 총비용

이번 표본의 비교 가능한 구간에서는 측정 영역 전체가 같은 RGB로 멈추는 현상을
포착하지 못했다. **95개 제외 샘플의 상태, 개별 유닛의 애니메이션 속도, 실제 모니터
표시 정지는 판정하지 않는다.** 영역 일부가 계속 변하면 특정 유닛의 정지가 있어도
변화로 집계되므로, 사용자 제보가 해결됐다는 근거로 사용하지 않는다.
